# Les repas de la semaine

Application web gratuite, sans compte, pour composer les dîners de la semaine et la liste de courses. Site : https://aycotek.github.io/Les-repas-de-la-semaines-/

## Ce que l'application fait

- Compose 7 dîners par semaine parmi 300 recettes classées par saison, 4 portions chacune (dîner + déjeuner réchauffé).
- Liste de courses regroupée par rayon, avec estimation de budget à partir de prix indicatifs (pas relevés en magasin).
- Repères nutritionnels approximatifs fondés sur la table CIQUAL 2020 (ANSES) et les repères ANSES/PNNS.
- Filtres indicatifs pour allergies (liste UE) et aliments à éviter ; pas une garantie médicale.
- Remplacement d'un repas ou ajout d'un 8e repas exceptionnel.
- Un dessin vectoriel par recette (illustrations, pas des photos des plats).

## Ce que l'application ne fait pas

Aucun compte, aucune synchronisation : les données restent dans le navigateur. Prix et nutriments sont des estimations. Sources : SOURCES.md.
